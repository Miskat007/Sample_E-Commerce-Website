SmartShop Starter Project
=======================

Quick start:
1. No npm install required — this starter uses Tailwind CDN for styling.
2. Open index.html with Live Server (recommended) or open it directly in browser.
3. Features included:
   - Responsive navbar (sticky)
   - Banner slider (auto + manual)
   - Product fetch from https://fakestoreapi.com/products
   - Shopping cart with subtotal, delivery, shipping, coupon (SMART10)
   - User balance system (default 1000 BDT) with Add Money (+1000) button
   - Reviews carousel (local JSON)
   - Dark/Light mode toggle (stored in localStorage)
   - Search & Sort
   - Contact form (demo)
